# ข้อมูลของโปรเจกต์

ข้อมูลทั้งหมดใน `policies.json` และ `inventory.json` เป็น **ข้อมูลสมมติที่ผู้พัฒนาและ AI สร้างขึ้นเพื่อการสาธิต** ไม่ใช่กฎหรือสถานะของชมรม/มหาวิทยาลัยจริง ไม่ใช่ corpus ของแอปตัวอย่างรายวิชา ไม่มีข้อมูลส่วนบุคคล

- 18 policy records: แต่ละ record เป็น chunk ตามหัวข้อ ไม่ตัดกลางเงื่อนไข มีข้อความไทยและคำแปลอังกฤษ
- 12 inventory records: snapshot คงที่สำหรับทำซ้ำการทดสอบ SQL ไม่มีการจองหรือชำระเงินจริง
- Policy ID ใช้เป็น citation ID; `source` ใน API ชี้ไปที่ไฟล์ข้อมูลและ ID นี้
- ใช้ข้อมูลนี้ได้ภายใต้ MIT license ของ repo นี้
- เมื่อเปลี่ยนนโยบายหรือ inventory ต้องแก้ labels และรัน eval ใหม่ ไม่ควรใช้เดโมกับงานยืมอุปกรณ์จริง
